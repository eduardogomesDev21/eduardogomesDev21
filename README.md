## 👨‍💻 Sobre Mim

Sou estudante de Análise e Desenvolvimento de Sistemas (FATEC), com foco no desenvolvimento de soluções voltadas à **automação de processos, organização e análise de dados, integração de sistemas e melhoria de fluxos operacionais**.

Tenho experiência no desenvolvimento de aplicações web, APIs REST e sistemas que simulam cenários reais de negócio, além da criação de automações para reduzir tarefas manuais, aumentar a eficiência e otimizar processos.

Busco sempre construir soluções que gerem valor prático para o dia a dia das empresas, utilizando tecnologia para **automatizar processos, integrar sistemas, organizar informações e apoiar a tomada de decisão**.

Tenho interesse em arquitetura de software, desenvolvimento Full Stack, integração de sistemas, automação de processos, análise de dados e uso de Inteligência Artificial aplicada a soluções de negócio.

## 💸 FinanceFlow

Sistema financeiro pessoal Full Stack para controle de receitas, despesas e acompanhamento da situação financeira através de dashboards interativos.

### 🔹 Destaques

* Autenticação com JWT e refresh token rotacionado
* Senhas criptografadas com BCrypt
* Rate limiting nas rotas de login
* CRUD completo de receitas, despesas e categorias
* Isolamento de dados por usuário
* Dashboard com indicadores e gráficos
* Filtros, paginação e ordenação
* Importação de CSV com validação
* Exportação para Excel e PDF
* Documentação da API com Swagger
* Arquitetura em camadas e tratamento global de exceções

### 🛠️ Stack

`Java 21` `Spring Boot` `Spring Security` `JWT` `JPA` `MySQL` `React` `TypeScript`
